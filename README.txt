SUCCESS ACHUENU — PERSONAL PORTFOLIO
===================================

Files
-----
index.html   Main page content
styles.css  Layout, colours, typography, responsive styles and animations
script.js   Mobile navigation, reveal-on-scroll effects and footer year

DESIGN DIRECTION
----------------
- Charcoal, warm ivory and muted copper.
- Manrope headings + DM Sans body text, with accessible system fallbacks.
- Background photography, foreground website-interface visuals and subtle motion.
- Responsive layout for phones, tablets and desktops.
- Reduced-motion preference is respected.

IMPORTANT BEFORE PUBLISHING
---------------------------
1. Confirm the contact email is correct..
2. Confirm the live Jedidiah project link is correct.
3. Review all copy and images before publishing.

IMAGES AND FONTS
----------------
The photography and Google Fonts are loaded from external services. A visitor needs an internet connection to load them. The website still has system-font fallbacks if Google Fonts cannot load.

PROJECT PREVIEW
---------------
The Jedidiah project image is a stylised portfolio preview built into the page, not a literal screenshot of the live website. The project title and link lead to the live client site. Replace the visual with a real screenshot when one is available.

HOW TO PREVIEW
--------------
You can open index.html directly in a browser. For local development, serve this folder with any simple static web server.

DEPLOY
------
Upload the contents of this folder to a static hosting service such as Netlify or Vercel. No build command is required; the publish/output directory is the project root.
